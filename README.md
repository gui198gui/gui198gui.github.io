# gui198gui.github.io

O meu portefólio pessoal: projetos, experiência, formação e certificados.

🔗 **https://gui198gui.github.io**

Feito com HTML e CSS (sem frameworks) e alojado gratuitamente no GitHub Pages.

## Como publicar

1. Cria no GitHub um repositório público chamado exatamente **`gui198gui.github.io`**.
2. Envia estes ficheiros para o ramo `main`.
3. Em *Settings → Pages*, confirma que a fonte é `Deploy from a branch` → `main` / `(root)`.
4. Ao fim de 1 ou 2 minutos o site fica disponível em https://gui198gui.github.io.

## Ficheiros

- `index.html`: conteúdo da página
- `style.css`: estilos
- `cv.pdf`: CV para download (adicionar)
